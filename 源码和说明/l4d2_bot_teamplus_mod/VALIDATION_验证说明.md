# Mod 0.1.2 验证说明

## 已执行

1. 使用 Squirrel 3.2 编译器解析两个 `.nut` 文件。游戏使用的 Squirrel 版本和引擎扩展不同，因此这是语法检查，不是游戏内加载证明。
2. 在独立 Squirrel VM 和简化游戏接口替身中执行行为检查：
   - 按键控制保留无关位，取消后恢复。
   - 真人接管时释放按键与临时武器选择状态。
   - Plan B 不在真人只是倒地而未死亡时启动。
   - 交换双方的原实体；部分失败不销毁物品。
   - 扶人被中断后重新计算连续时间。
   - 危险区域的基本高度区分。
   - 临时跳过失败目标，实体编号重用不继承旧状态。
   - 按钮由匹配的输出标记成功。
   - 配置数值边界和无效文本处理。
   - 支持模式启动、其他模式停用、关闭时恢复变量。
3. 使用单文件 VPK v1 结构打包，再用独立 ValvePython `vpk` 读取所有文件，检查 CRC 和与源文件逐字节一致性。
4. 0.1.1增加通过已公布的游戏事件分发代码调用聊天回调的测试：全局 `GetPlayerFromUserID` 不存在时仍能回复、字符型用户ID和空白处理、多次注册不重复回复、不删除其他Mod回调、事件表清空后恢复、非房主不能管理、异常显示提示。此前测试没有覆盖这条聊天分发路径。

5. 0.1.2增加默认允许酸火、在酸火中连续救援、旧配置迁移和迁移后保留用户手动选择的模拟测试。

## 未执行

没有运行 L4D2 客户端/服务器，没有验证游戏内导航、完整动画、Bot切枪、射击命中、实际投掷、除颤/铺包、地图按钮、油桶搬运和多人接管。这些不能用模拟测试结果代替。

## 游戏内验收建议

先只开启这个 Mod：

- 单机战役中 `!btp` 能显示运行状态，控制台无脚本报错。
- 检查 Bot 清怪、扶人中断、进入酸火区域后继续救援（配合免伤包）。
- 双方拿不同投掷物测试右键交换；交接时走远，确认失败不会丢失/复制原物品。
- 放置尸体与除颤器、给Bot升级包，检查实际使用及库存消耗。
- 测试远处尸群自动投掷，以及低天花板/队友靠近落点时放弃投掷。
- 在官方灌油终章测试拾油、搬到机器旁、遇敌中断放桶。
- 登记一个普通和一个长按按钮；真人死亡后检查 Plan B，不应强开锁定机关。
- 真人接管搬油/使用物品中的Bot，检查能正常选择和使用主副武器。
- 关闭Mod、重开回合、换图，确认无遗留强制输入。
- 最后再加入你常玩的第三方图和其他Mod，逐项排查兼容。

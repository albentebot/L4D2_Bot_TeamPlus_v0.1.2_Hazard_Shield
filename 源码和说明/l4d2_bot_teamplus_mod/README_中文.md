# Bot TeamPlus MOD 0.1.2

0.1.2 默认关闭酸液和火焰避让：不再因为脚下或目标处有酸液/火焰而取消救援、物资或搬油任务。首次升级自动把旧配置的 avoid_spit 改为0，其他配置保留。配合单独的 Survivor Hazard Shield VPK 使用，可让真人和 Bot 免疫酸火伤害。保留0.1.1的聊天命令修补。

**`!btp` 是聊天命令。控制台里应输入 `say !btp`，直接输入 `!btp` 会显示 `Unknown command`。** 请删除旧版VPK后替换为新版，完全退出游戏再打开；原有 `ems/bot_teamplus` 配置可以保留。

这是你之前那套 Bot 增强需求的 **独立 VScript / VPK 版本**。使用游戏自带脚本接口，不需要 SourceMod、Metamod、Left4DHooks、Left 4 Bots 或 Left 4 Lib。

包内提供 `bot_teamplus_mod.vpk`、完整源码、可重新打包的工具和验证说明。

**当前是测试版。已完成 Squirrel 语法检查、模拟环境的状态/物品测试，以及 VPK 结构和内容校验；未运行 L4D2 实战测试。** 实际操作是否成功仍受游戏使用判定、Bot 原生逻辑、导航网格、地图脚本和其他 Mod 影响。

## 安装，直接用 VPK

1. 将 `bot_teamplus_mod.vpk` 复制到：

   ```text
   Steam/steamapps/common/Left 4 Dead 2/left4dead2/addons/
   ```

2. 在游戏的“附加内容”中启用 **Bot TeamPlus MOD (Standalone VScript)**。
3. 开启**单机战役、写实模式，或自己作为房主的本地服务器**。
4. 按Y在聊天栏输入 `!btp`，或在控制台输入 `say !btp`，应显示版本和“运行中”。控制台应出现 `[TeamPlus MOD 0.1.2] loaded`。

只需放入 VPK，不要把源码文件夹也重复安装。加入官方服务器或别人的服务器时，仅在自己电脑安装不能改变服务端 Bot。独立服务器可将 VPK 安装到服务器，但本版聊天管理命令只授权本地房主；独立服务器应直接编辑配置并重开地图。

**不要同时启用之前的 SourceMod TeamPlus 插件和这个 Mod。** 也建议先停用 Left 4 Bots / Left 4 Bots 2 等其他全面控制 Bot 的 Mod 后单独测试。纯贴图、模型 Mod 通常不涉及同类控制，但自定义人物碰撞/骨骼仍可能影响瞄准。

## 包含的功能

| 功能 | 脚本版实现 |
| --- | --- |
| 战斗增强 | 更积极地瞄准可见敌人；优先解救被特感控制的队友，优先处理近身小僵尸，自动推击和空弹匣换弹。不主动将 Witch 加入攻击目标。 |
| 快速扶人 | 主动接近倒地/挂边队友；Bot 连续扶人默认 2 秒后复起。中断后重新计时；不修改真人扶人时间。 |
| 投掷物 | 默认土制炸弹和胆汁；满足尸群数量、落点距离、队友距离及路线检查后，实际切到投掷物、按住攻击并松开，由游戏投出和消耗。燃烧瓶可选，只针对合适距离的 Tank。 |
| 除颤器 | 携带除颤器时寻找可到达的尸体，走近切换并使用，由游戏完成除颤。 |
| 升级弹药包 | 安全且至少两名幸存者在附近时使用燃烧/高爆弹药包。 |
| 右键交换 | 手持投掷物，近距离瞄准 Bot 按右键。双方都有就互换；Bot 没有就交给它。 |
| 自动交补给 | 玩家空槽位时交药、急救包、投掷物；不覆盖已有物品。Bot 有效血量低于35时保留自己的药和急救包。 |
| 穿过酸液/火焰 | 默认允许增强任务使用酸火区域，不再主动逃离或取消救援；原版导航仍可能绕路。免伤由单独的 Hazard Shield 提供。 |
| 反应速度 | 请求每0.05秒执行一次脚本思考，实际频率受游戏调度限制；世界列表每0.25秒刷新。 |
| Plan B | 所有真人幸存者死亡且无可执行除颤机会时，尝试已登记的机关；默认也会尝试附近可见普通按钮。 |
| 搬油 | 自动尝试识别 `c1m4_atrium` / `c6m3_port` 的灌油目标，或使用自定义送油点。一次一个 Bot 搬真实油桶到机器旁放下，**不自动灌油**。 |

任务还有占用锁、超时、走路无进展取消、目标失效处理。搬油遇到贴身威胁时取消并放下油桶。玩家接管 Bot 时会清除本 Mod 添加的按键控制并恢复临时武器状态。

## 物品交换与 SourceMod 版的区别

本版通过“放下原物品 → 接收者使用同一个实体”完成交换，存在短暂的地面交接过程。没有生成复制品，也不会删除原物品以伪装交换成功。

交接可能被第三人拾取、死亡、移动距离、游戏动作状态打断。脚本会核对接收结果，失败时尽量归还；无法归还的原物品会留在当前持有者或地面，可能不是原来的归属。因此不要把它理解成瞬间、不可打断的交易。

右键按键通过周期检测识别，极短的点击可能被漏过，未拦截真人原本的推击动作；瞄准 Bot 并正常点击即可。交换距离约150游戏单位，主动递物约160单位。

## 聊天命令

所有玩家可用：

```text
!btp                      查看运行状态
!btpgive                  索取一件自己空槽位的补给
```

以下命令仅本地房主可用：

```text
!btpoff                   关闭增强，释放 Bot 控制
!btpon                    开启增强
!btpreload                重载配置和地图规则，取消当前任务
!btpset throw_mask 7      土制、胆汁、燃烧瓶全开
!btpset revive_seconds 1.5
!btpset planb 1           只按登记过的按钮
!btpmark button 5         登记当前瞄准的按钮及5秒操作时间
!btpmark gas              登记当前瞄准的灌油机旁送油位置
```

重载会重新建立按钮观察状态。不要在已经运行到一半的复杂机关流程中反复重载；需要保留已触发机关状态时应正常玩到下一回合。

## 设置文件

首次启动会在游戏中创建：

```text
left4dead2/ems/bot_teamplus/settings.txt
```

修改后使用 `!btpreload` 或重开地图。也可以直接用 `!btpset` 保存修改。

| 设置 | 默认 | 含义 |
| --- | --- | --- |
| combat | 1 | 战斗输入增强 |
| rescue | 1 | 主动快速救援 |
| revive_seconds | 2.0 | Bot连续扶人时长，0使用原版完成时间 |
| defib | 1 | 使用除颤器 |
| upgrade | 1 | 使用升级弹药包 |
| throw_mask | 3 | 1土制、2胆汁、4燃烧瓶，相加组合，7全开 |
| throw_count | 8 | 土制/胆汁需要的尸群数量 |
| share | 1 | 主动分物资 |
| share_health | 100 | 玩家有效血量不高于此值时可获药/包 |
| avoid_spit | 0 | 0允许任务穿过酸火；1恢复旧版避让 |
| planb | 2 | 0关闭；1仅地图规则；2另尝试附近普通按钮 |
| gas | 1 | 寻油和搬运 |
| task_range | 1600 | 寻路目标最大直线距离 |
| debug | 0 | 控制台显示任务切换信息 |

想提高强度可以尝试 `revive_seconds=1.5`、`throw_count=6`。燃烧瓶默认关闭，因为检查只能减少风险，无法保证移动目标、队友跑位下完全无友伤。本版没有无限弹药、无敌、额外伤害或瞬移搬油。

## 第三方图：登记按钮和送油点

在正确的操作位置站稳，瞄准真实按钮，用 `!btpmark button 5` 登记。长按按钮可调整秒数，范围0.2–20秒。普通按钮、旋转按钮和长按按钮分别要求实体类型为 `func_button`、`func_rot_button`、`func_button_timed`。显示出来的装饰模型不一定是真正的按钮实体，瞄准模型而不是按钮时登记会失败。

送油时站在希望 Bot 放桶的地面位置，瞄准灌油机或其具有稳定地图标识的实体，输入 `!btpmark gas`。不要隔墙登记，也不要站在无法导航的位置。送油点登记后不要求目标恰好是原版灌油实体，方便第三方图使用装饰机体作为参照。

规则写入：

```text
left4dead2/ems/bot_teamplus/maps/地图名.txt
```

格式每行一条：

```text
# 类型|targetname或#HammerID|站位X|站位Y|站位Z|持续秒数
button|actual_button_name|100.0|200.0|16.0|5.0
gas|actual_machine_name|300.0|400.0|16.0|5.0
```

上面是结构示例，不是可直接套用的真实地图坐标。程序优先保存 Hammer ID，否则保存 targetname。无稳定标识的运行时实体不能持久登记。

按钮按文件顺序处理，未出现、锁住或不可到达的前序按钮会阻止跳到后序按钮。只有收到真实 `OnPressed` / `OnTimeUp` 输出才认为完成，不会隔空强行触发机关。默认通用模式只找附近约250单位内的普通按钮，**不是完整的自动跑图或解谜系统**。复杂前置条件、多玩家同步开关、重复按同一按钮、自定义脚本实体需要进一步按图开发。

## 限制和排错

- 仅战役 `coop` 和写实 `realism` 默认运行，对抗/清道夫/生还者及 Mutation 不开启。
- 需要有效导航网格。不能修复地图本身的断路、缺失导航、特制互动条件。
- 关闭本 Mod 的酸火避让并不替换原版寻路器：原版 Bot 仍可能绕路，不能保证每次直穿火区。缺导航、实体阻挡和地图禁止通行区仍无法穿过。
- 投掷使用游戏正常动画和物理；高低差、天花板、移动队友仍可能影响结果。抛物路线检查只是近似判断。
- 为防止搬油或使用物品时原版 Bot 自动切枪，脚本暂时锁定它当前主副武器的选择，结束任务或接管时恢复。不要让其他 Mod 同时控制这些状态。
- 启用时将 `sb_all_bot_game` 和 `allow_all_bot_survivor_team`（若存在）设为1，使真人死亡后 Bot 继续。关闭时尝试恢复原值。
- 每次扫描最多缓存256个普通感染者和64个火焰/酸液实体，超出部分不保证被增强逻辑检测到。
- 本次启动累计脚本错误达到3次会停止增强并在控制台报错，避免保留强制控制状态。
- 未经过真实服务器测试，不能承诺换图、特殊模型、超四人或自定义地图下全部无误。若出现问题，先 `!btpoff`；保留控制台的 `[TeamPlus ERROR]`、地图名、模式、其他Mod列表和复现步骤。
- 如果 `!btp` 完全没有响应，检查附加内容是否启用、房间是否由自己本地托管，以及控制台是否有脚本加载错误。不要仅靠打开 `sv_cheats` 排错，本 Mod 不以它作为正常安装步骤。

## 源码与重新打包

源码位于 `source/`。修改 `source/scripts/vscripts/bot_teamplus/core.nut` 后，在这个包目录运行：

```text
python build_vpk.py
```

需要 Python 3，不需第三方 Python 库；工具会重建本目录下的 `bot_teamplus_mod.vpk`。将新 VPK 替换到游戏 `addons` 后重启游戏。脚本设置优先使用 `ems` 里的已有设置。本次有一次迁移：若没有 `ems/bot_teamplus/hazard_walk_012.txt` 标记，会保存 `avoid_spit=0`；之后保留用户的新选择。卸载免伤包后想恢复避让，可在聊天输入 `!btpset avoid_spit 1`。

本 Mod 使用 `director_base_addon.nut` 作为加载入口和独立命名空间，没有覆盖 `coop.nut` 或游戏原始 Director 脚本。属于同一个 Bot 的不同控制 Mod 仍可能产生行为冲突。
